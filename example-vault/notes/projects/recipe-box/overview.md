# Recipe box

## What
- A small web app where the family stores recipes with photos of the original cards.
- Search by ingredient ("what can I make with leeks").
- Scale a recipe to a different number of servings.

## Users
- About 12 relatives, most on phones, two over 75. Large text and no passwords.

## Stack
- Python, FastAPI, server-rendered HTML with htmx, SQLite, one small VPS.

## Status
- Data model and import done. Login and photo upload in progress. Target: family dinner on 2026-12-20.
